Wiring n8n to Grafana

Nine steps to get n8n's blocked-IP alerts safely recorded into Grafana.

1

Default Login Didn't Work

admin/admin was rejected — this Grafana had a different password set.

2

Found the Real Password

Read it from Grafana's own container configuration.

3

Created a Service Account

A non-human login just for n8n, with only Editor access — not full Admin.

4

Generated an Access Token

Issued once by Grafana and captured immediately — it can't be viewed again.

5

Tested the Token First

Confirmed it could actually write to Grafana before trusting it anywhere.

6

Saved It as an n8n Credential

Stored securely so n8n sends it automatically with every request.

7

Linked It to the Right Step

Attached to the exact workflow node that posts results to Grafana.

8

Used the Correct Address

Pointed to host.docker.internal, since n8n and Grafana are separate containers.

9

Connected — Dashboard Still to Come

The link works end-to-end; next is building a Grafana dashboard to see it.
