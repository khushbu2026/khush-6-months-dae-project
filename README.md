# Khushbu Jalan | Cybersecurity & Technology Learning Portfolio

**Six months of hands-on learning at dae** · Cybersecurity · Python · Linux · Security Operations

Welcome! This repository documents my transition from a background in retail leadership and entrepreneurship into technology and cybersecurity. Over six months at dae, I explored technical foundations, practiced with security tools, and developed projects to apply what I learned.

I am building toward an **entry-level Security Operations Center (SOC) Analyst** career. This portfolio reflects my learning process, including experiments, challenges, and improvements.

My main project explores how security monitoring and automation can work together using accessible tools. Topics in my project work include Wazuh, log collection, alerting, cloud infrastructure, and workflow automation.
